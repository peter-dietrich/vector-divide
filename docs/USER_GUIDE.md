# Vector Divide — macOS Help

Territory-capture arcade — Classic and Modern

## How to play

Claim territory by drawing lines from a protected border and reconnecting before enemies reach your open trace. Capture at least 75% of the field to advance. Classic and 3D Modern share game rules.

## Controls

| Control | Action |
|---|---|
| Return | Start, advance level or restart. |
| Arrow keys / WASD | Move along the protected border or draw an open trace. |
| Hold Space + direction | Fast trace for reduced points. |
| Hold Shift + direction | Slow trace for doubled points. |
| P | Pause or resume. |
| R | New game. |
| Click game board | Restore keyboard focus. |

## Records and saving

The game saves records, named presets, and resumable sessions locally using its own preferences. Use the game's Save, Resume and Custom Game controls; no progress is sent to GitHub.

## Mac menus

Select **Game → How to Play**, **Controls & Shortcuts** or **Scores & Saving**. The Help menu opens the built-in offline manual. Existing gameplay shortcuts are unchanged.
